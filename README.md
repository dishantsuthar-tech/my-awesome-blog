# My Awesome Blog

A simple multi-page blog website built using HTML5 as part of my web development learning journey.

## 🌐 Live Demo

**[View My Awesome Blog](https://dishantsuthar-tech.github.io/my-awesome-blog/)**

## ✨ Features

- Blog posts with images and lists
- Contact form with input validation
- 10-digit phone number validation
- Success page after form submission
- Navigation between pages

## 🛠️ Technologies Used

- HTML5

## 📂 Project Structure

```text
my-awesome-blog/
├── index.html
├── contact.html
├── success.html
└── README.md
```

## 🚀 Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.
3. Explore the blog and test the contact form.

## 📝 Note

This is a beginner practice project. The contact form does not store or send submitted data to a server.
